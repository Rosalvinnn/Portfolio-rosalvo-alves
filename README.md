
# 💻 Portfólio Pessoal — Rosalvo Alves

## 📌 Sobre o projeto

Este projeto consiste em um portfólio pessoal desenvolvido para apresentar minha trajetória como estudante de tecnologia, minhas competências e alguns dos projetos que desenvolvi durante minha formação acadêmica.

O portfólio também conta com uma página interativa do Jogo da Forca, desenvolvida para praticar lógica de programação e desenvolvimento web.

## 🎯 Objetivos

- Apresentar minha formação e minhas competências.
- Compartilhar projetos acadêmicos e pessoais.
- Praticar desenvolvimento de interfaces web.
- Desenvolver uma aplicação interativa utilizando Next.js.

## 🛠️ Tecnologias utilizadas

- JavaScript
- React
- Next.js
- HTML
- CSS

## 📂 Projetos apresentados

### 🎲 Jogo de Dados

Jogo desenvolvido para dois participantes, com cinco rodadas, lançamento de dados e contagem de vitórias.

**Tecnologias:** Next.js, JavaScript e CSS.

### 🚪 Sistema de Controle de Acesso RFID

Projeto de robótica e automação que utiliza Arduino e identificação por cartão RFID para controlar o acesso por meio de uma maquete de portão.

**Tecnologias:** Arduino, RFID e programação.

[🔗 Acessar repositório no GitHub](https://github.com/Rosalvinnn/Sistema_De_Controle_De_Acesso_RFID/tree/main)

### 🏥 Sistema de Clínica

Projeto acadêmico de banco de dados para organização de informações relacionadas a pacientes, médicos, consultas e receitas.

**Tecnologias:** MySQL e SQL.

### 🌐 Prática com DNS

Projeto acadêmico de Redes de Computadores que explora a resolução de nomes de domínio e a configuração de um ambiente local para acessar um portal utilizando um domínio.

**Tecnologias:** DNS, Flask, Python e MySQL.

[🔗 Acessar repositório no GitHub](https://github.com/C3NEXT/redes-computadores-dns)

### 🚗 Sistema de Concessionária

Sistema desenvolvido para gerenciamento de uma concessionária, integrando front-end, back-end e banco de dados para organizar veículos, usuários e vendas.

**Tecnologias:** Desenvolvimento web e banco de dados.

[🔗 Acessar repositório no GitHub](https://github.com/NextCar-Project/projeto-next-car)

### 🎮 Jogo da Forca

Jogo interativo no qual o jogador precisa descobrir uma palavra secreta antes que suas tentativas acabem.

O jogo possui teclado interativo, identificação de letras corretas e incorretas e condições de vitória e derrota.

**Tecnologias:** Next.js, React, JavaScript e CSS.

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

É necessário ter o Node.js e o npm instalados.

### 2. Clonar o repositório

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

### 3. Entrar na pasta do projeto

```bash
cd SEU-REPOSITORIO
```

### 4. Instalar as dependências

```bash
npm install
```

### 5. Executar o projeto

```bash
npm run dev
```

Depois, abra o navegador e acesse:

http://localhost:3000
